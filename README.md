# 幸運輪盤（Lucky Draw）

揀唔落手就轉一轉。由 Bill Chiu 開發。

- 撳「轉！」、撳中間「轉」，或者用手指撥個輪盤
- 右上角 ✏️：加／改／刪抽咩、×2 加大機會、一次過貼上清單、幾個輪盤切換
- 淘汰模式：抽中嘅自動踢走，再轉
- 資料存喺手機瀏覽器（localStorage），唔會上載

## 安裝
GitHub Pages：Settings → Pages → Deploy from a branch → `main` → `/ (root)`。
iPhone 用 Safari 開網址 → 分享 → 加入主畫面。

## 上載新版本
改 `index.html` 入面 `window.__LUCKY_VER` 版本號，手機開 App 會自動更新。
